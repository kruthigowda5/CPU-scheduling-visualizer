# CPU Scheduling Algorithm Visualizer
An interactive web-based simulator that visualizes how CPU scheduling algorithms work using real-time Gantt charts, step-by-step execution, ready queue tracking, and performance comparison.
## Features
- Supports FCFS, SJF, and Round Robin scheduling
- Step-by-step execution mode
- Dynamic Gantt chart visualization
- Ready Queue and CPU state tracking
- Waiting Time & Turnaround Time calculation
- Algorithm comparison using charts
- Add processes dynamically
## Tech Stack
- HTML
- CSS
- JavaScript
- Chart.js
## How to Run
1. Clone the repository  
   git clone https://github.com/kruthigowda5/CPU-scheduling-visualizer
2. Open the project folder
3. Run `index.html` in your browser
## Performance Metrics
The simulator calculates:
- Waiting Time
- Turnaround Time
- Average Waiting Time
- Average Turnaround Time
These help compare the efficiency of scheduling algorithms.
## Real-World Relevance
CPU scheduling is used in operating systems, servers, cloud platforms, and embedded systems to decide which process gets CPU time and to improve system performance.
